# RTI Sahayak

Turns a plain-language grievance into a properly formatted RTI application,
addressed to the correct government department, in under a minute.

Built for OOSC 4.0 Hackathon — Problem Statement 3 (AI for Civic and Legal Empowerment).

## Run locally
1. `npm install`
2. Copy `env.example` to `.env` and add your Groq API key
3. `node server-groq.js`
4. Open `RTI_Sahayak_FrontendFinal (1).html` in a browser
